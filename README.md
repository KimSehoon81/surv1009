# 6.25 서바이벌

6·25전쟁 배경 레트로 2D 도트 서바이벌 액션 + 성공 30% 확률형 전략카드 조합 스킬 게임.
낙동강에서 압록강까지 10개 지역을 남에서 북으로 점령합니다. 한 판(약 15분)은 **버티며 성장 → 보스 격파 → 점령**입니다.

## 플레이

- 웹: GitHub Pages(저장소 Settings → Pages → Source를 **GitHub Actions**로 두면 main에 푸시할 때마다 `https://<계정>.github.io/surv1009/`에 배포)
- itch.io: `npm run package` → `dist-zip/amnok-survival-<버전>.zip`을 HTML 게임으로 올리고 "This file will be played in the browser"
- 로컬:

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run check      # 타입 검사 + 테스트 + 빌드(커밋 전 필수)
npm run test:e2e   # 브라우저 스모크 테스트(부팅 → 지도 → 전투 30초 → 결과, 콘솔 오류 0)
npm run build      # dist/ 에 배포용 빌드 (build:release는 아틀라스까지, Python Pillow 필요)
```

## 모바일·배너

- 휴대폰·태블릿으로 같은 주소를 열면 **터치 조작판**이 나옵니다. 전투: 화면 왼쪽을 끌어 이동(조이스틱), 오른쪽에 `질주`·스킬 `Q E R F`·카드 `제출`/`인장`·`Ⅱ`. 카드는 손패를 직접 누릅니다. 메뉴: 방향 버튼 + `확인`/`뒤로`(항목을 직접 눌러도 됨)
- 세로로 들고 있어도 게임이 **가로 화면**으로 돌아 나옵니다(회전 잠금과 무관). 안드로이드는 `⛶`로 전체 화면 + 가로 고정
- PC에서 조작판을 보려면 주소에 `?touch=1`. 버튼 구성은 `src/data/touch.json`
- 사이트에 넣는 **배너 슬라이드** 코드(PC·모바일, 누르면 새 창): [docs/BANNER.md](docs/BANNER.md)

## 조작

생각은 멈춘 화면(레벨업·작전판)에서, 전투 중에는 키 하나로. 키는 설정 → 키에서 바꿀 수 있습니다.

| 행동 | 키보드 | 패드 |
| --- | --- | --- |
| 이동(사격은 자동) | WASD / 방향키 | 왼쪽 스틱 |
| 질주(1초, 처음 잠깐 무적, 7초마다) | C | 왼쪽 스틱 누르기 |
| 카드 고르기·해제(최대 3장) | 1~5, 클릭 | 방향 패드·오른쪽 스틱 좌우 + X |
| 작전 개시(빈 선택이면 첫 입력은 추천 조합 채우기) | Space / Enter | A |
| 인장 걸고 제출(확정 성공) | Shift+Space | Y 길게 |
| 선택 해제 | X / Backspace | B |
| 고급 스킬 1~4 | Q · E · R · F | LB · RB · LT · RT |
| 작전판(일시정지 + 조합표·확률) | Tab | View |
| 일시정지 | Esc | Start |

전투 중 기믹: 보급 투하 상자·우방군 지원 분대·엘리트의 보물 상자(열면 업그레이드 1·3·5개)·자석(경험치 별 전부 회수)·보스 작전 카드 충전 중 약점(집중 사격으로 취소)·굽이치는 개울(건너면 잠깐 느려짐)·폭발이 가까우면 떠나는 소·호랑이·진돗개·마을 주민·**돌격대**(방향 화살표로 예고, 30초 안에 전부 격퇴하면 자석 보급 + TP).

- **고지 점령**: 간간이 푸른 원(점령 지점)이 생깁니다. 원 안에서 7초 버티면 태극기가 올라가며 점령 — 체력 회복, 20초간 공격력·이동 속도 상승, 스킬 게이지 +20, 주변 적에게 충격파. 원 밖에 있으면 올린 만큼이 내려가고 40초 안에 못 올리면 사라집니다
- **구사일생**: 판마다 한 번, 쓰러질 피해를 받아도 체력 25%로 버팁니다(잠깐 느려지며 주변 적을 밀어내고 2.5초 무적)
- **눈부심**: 스킬(Q·E·R·F)을 쓰거나 카드 작전이 성공하면 빛이 터지고 전용 효과음이 납니다. 체력이 낮으면 심장 박동 소리. 번쩍임은 설정의 '타격감 강도'를 따릅니다

화면의 말: **스킬 게이지**(스킬에 쓰는 힘, 영문판 TP) · **인장 조각**(작전이 실패할 때마다 1개, 10개가 모이면 반드시 성공하는 인장) · **적 강도**(시간이 갈수록 적이 강해지는 정도)

손맛: 예광탄 궤적, 쓰러진 적이 맞은 방향으로 튕겨 사라지는 잔상, 한꺼번에 여럿 쓰러뜨리면 `X12` 다중 처치 연출, 스킬 발동 충격파와 이름표, 작전 성공·실패 도장, 체력이 낮으면 화면 가장자리 붉은 맥박.

점령하면 미션 클리어 화면의 지도에서 다음 목표를 보여 주고 Enter로 바로 다음 지역 출정. Esc 일시정지 메뉴에서 계속하기·작전지도로 철수·메인 메뉴로 철수. 출정 준비의 **성장 지도**: 캐릭터마다 숙련(그 캐릭터로 번 전공)이 쌓여 레벨마다 포인트 2. 6갈래(고유·화력·기동·보급·작전·생존) × 5단계와 갈래 사이 연결 칸 6개, 모두 36칸. 바깥 단계일수록 비용(1·2·3·4·6)과 필요한 숙련 레벨이 오르고, 연결 칸은 양쪽 갈래의 2단계가 모두 필요하며, 5단계 정점은 캐릭터당 2개까지라 방향을 골라야 합니다.

레벨 10에 보스가 나온 뒤에도 별을 모으면 계속 레벨이 오릅니다(최대 30). 대신 10을 넘는 레벨마다 보스의 공격이 4%씩 잦아집니다(예고 시간은 그대로).

설정에서 언어(한국어 / English), 화면 흔들림·점멸 강도, 이펙트 품질, 신병 모드, 판정 연출 짧게 등을 고를 수 있습니다. 저장이 이상해지면 설정 → "마지막 정상 세이브로 되돌리기".

## 표현 원칙

역사적 배경을 존중하되 표현은 게임답게 합니다.

- 혈흔·신체 훼손 없음(스파크·먼지·연기로 대체), 민간인 피해 묘사 없음
- 실존 인물 실명·초상 미사용(지휘관은 직책명), 외모 희화화 금지(군복·장비·실루엣으로만 진영 구분)
- 엔딩 크레딧에 함께한 전투 지원·의료 지원 국가를 적습니다

## 개발용 주소

- `?debug=1` 디버그 키(J공격 K방어 L스킬 U치명 I무적 F2적300 …)·계측 표시, `?stage=S5` 시작 스테이지, `?char=A02` 시작 캐릭터
- 전투는 판마다 새 시드라 카드 순서·레벨업 선택지·지형이 매번 다릅니다. 같은 판을 다시 보려면 콘솔의 `[battle] seed …`를 `?seed=…`로
- `?auto=stage1&speed=8&seed=1` 자동 진행(메뉴부터 전투·결과까지 스스로), `?reset=1` 저장 초기화 (2지역부터는 앞 지역을 점령한 저장이 있어야 지도에서 넘어감)
- `?gallery=1` 그래픽 갤러리, `?gallery=audio` 소리 검수, `npm run assets:check` 그래픽 규격 검사
- 그래픽은 `public/assets/` 아래에 규격대로 PNG를 넣으면 자동으로 교체됩니다(없으면 자리표시자). 규격은 [docs/ASSETS.md](docs/ASSETS.md)
