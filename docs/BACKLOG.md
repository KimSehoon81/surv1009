## 3. 게임성 개선 아이디어

- 원거리 적 대응: 종류별 동시 상한(maxAlive)으로 쌓임은 막았음. 다음 단계로 "사거리 안 원거리 적 우선 조준" 설정 옵션을 사람 플레이 뒤 검토
- 레벨업 간격: Lv3 이후 1분에 1이 느리게 느껴지면 levels.json 곡선을 Lv4~8만 10~15% 당기기(보스 Lv10 조건과 함께 봐야 함)
- 다중 처치 연출: 범위 공격으로 한꺼번에 여럿 쓰러질 때 짧은 펀치(지금은 콤보 카운터·소리 음계만)
- 패드 버튼 아이콘을 글자 대신 그림으로(지금은 A·B·LB 같은 글자)
- 키 재설정에 패드 버튼 재설정 추가(지금은 키보드만)
- 도전 과제·일일 시드(같은 시드로 기록 경쟁)

## 4. 기술

- GitHub Pages: 저장소 Settings → Pages → Source = GitHub Actions(워크플로 `.github/workflows/pages.yml`)
- 배포 빌드 아틀라스: `build:release`는 Python Pillow 필요(워크플로는 설치함)
- e2e를 CI에 넣기(지금은 로컬 `npm run test:e2e`만, 약 20초)
- 세이브 버전 v2가 생기면 `src/core/save.ts` MIGRATIONS에 한 줄 + `tests/fixtures`에 샘플 추가
