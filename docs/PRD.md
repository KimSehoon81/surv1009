## 1. 제품 개요

**한 줄 소개** 6·25전쟁을 배경으로 한 레트로 2D 도트 뱀파이어 서바이벌류 액션에, 성공 30%·실패 70%의 확률형 전략카드 조합 스킬을 결합한 게임.

| 항목 | 내용 |
| --- | --- |
| 장르 | 탑다운 2D 서바이벌(자동공격) + 확률형 카드 조합 + 로그라이트식 메타 성장 |
| 그래픽 | 레트로 2D 도트, 메탈슬러그(Metal Slug)풍 — 굵은 외곽선·채도 높은 셀 셰이딩·과장된 애니메이션 |
| 플레이 시간 | 스테이지당 12\~15분, 10스테이지(1회 완주 약 2.5\~3시간) |
| 플랫폼 | PC 우선, 브라우저(HTML5) 프로토타입으로 먼저 검증 — 확정 필요 |
| 입력 | 키보드(WASD·숫자키·Q E R F), 마우스, 패드는 추후(키 배치는 3장 조작 표) |

**핵심 재미 3축**

1. 뱀서식 대량 학살의 쾌감과 강한 타격감
2. 30%에 거는 카드 도박, 그리고 조합이 만드는 대형 스킬 연출
3. 스테이지 점령 → 레벨 리셋 → 더 좋은 출발선(스타팅 포인트)으로 재진격

**진영과 연출 원칙**

- 아군: 대한민국 국군 + 미군 + 유엔군 참전국(영국·터키·캐나다·호주·에티오피아·그리스·필리핀·프랑스·네덜란드·태국 등)
- 적군: 조선인민군(북한) + 중공군(중국인민지원군)
- 역사적 배경을 존중하되 표현은 게임답게: 혈흔·신체 훼손 없음(스파크·먼지·연기로 대체), 민간인 피해 묘사 없음, 실존 인물 실명·초상 미사용(지휘관은 직책명), 외모 희화화 금지(군복·장비·실루엣으로만 진영 구분)

## 3. 게임 구조와 코어 루프

**화면 흐름** 메인화면(목업 대기) → 한반도 작전지도(스테이지 선택) → 출정 준비(캐릭터·덱·고급스킬 슬롯·스타팅 포인트) → 전투 Lv1\~Lv10 → 보스전 → 점령 연출 → 전공 정산 → 작전지도

**한 판(스테이지 런) 타임라인**

| 레벨 구간 | 시간(약) | 내용 |
| --- | --- | --- |
| Lv1\~3 | 0\~4분 | 소수 적, 카드 가이드, 첫 조합 체험 |
| Lv4\~6 | 4\~8분 | 엘리트 등장, 방해 요소 시작, NPC 이벤트 |
| Lv7\~9 | 8\~12분 | 대군집, 마이너스 카드 혼입 증가 |
| Lv10 | 12\~15분 | 스테이지 보스전, 처치 시 점령 |

**진행 원칙(v0.2)**: 새 요소는 1분에 1개 이하. 몰아치는 구간(대군집 90초) 뒤에는 20초 숨 고르기(스폰 −50%). 엘리트 첫 등장 3초 전, 방해 10초 전, 보스 15초 전에 예고. 스테이지 1 기준: 0\~1분 이동 익히기 → 1\~4분 첫 조합 → 4:00 엘리트 → 5:00 첫 방해 → 6:00 NPC → 7:30 숨 고르기 → 8\~12분 대군집 2회 → 보스.

**해석(레벨)**: 레벨 = 전투 중 성장 단계. 스테이지당 Lv1\~10, 전체 100단계(전역 단계 N = (스테이지−1)×10 + 스테이지 내 레벨). 스테이지를 점령하면 캐릭터 레벨과 임시 업그레이드가 리셋됩니다.

**조작**

원칙: **생각은 멈춘 화면(레벨업·작전판)에서, 전투 중에는 키 하나로.** 모든 입력은 액션 이름으로 처리해 키 재설정·패드가 바인딩 추가만으로 되게 한다.

## 4. 전투와 성장

**4.1 플레이어 스탯** 체력, 방어력, 이동속도, 공격력, 공격속도, 범위, 치명타 확률(기본 5%)·배율(기본 ×2.0), 자석 범위, 행운(레어 업그레이드·카드 품질 보정).

**4.2 레벨업** 적 처치 시 경험치 보급품(별 모양 도트)이 떨어지고, 레벨업하면 3지선다 업그레이드가 열립니다.

- 기본 레어도 확률: 일반 60 / 우수 28 / 희귀 10 / 전설 2 (%) — 카드·행운으로 상향
- 선택지: 기본 무기 신규·강화, 패시브(체력·이속·공속·범위·치명·자석·행운), 카드 보너스(손패 +1, 드로우 속도 등)
- 필요 경험치: Lv1→2는 20, 이후 단계마다 ×1.35 (Lv9→10은 약 220)

- 추가 연출: 연속 처치 콤보 카운터(처치음이 5음 음계로 한 칸씩, 최대 1옥타브), 적 스쿼시&스트레치, 탄피 배출, 총구 화염, 피격 시 화면 가장자리 붉은 비네팅, 패드 진동
- 성능 가드: 동시 파티클 300개, 데미지 숫자 40개 상한, 히트스톱은 중첩하지 않고 최댓값만 적용
- 정지 예산(v0.2): 화면 전체 정지는 치명 이상만, 길게 보아 전체 시간의 20% 이하(대형 처치는 예외). 프레임당 전체 연출 6건(대형·스킬 > 치명 > 일반), 나머지는 점멸·넉백·숫자만. 화면 밖 타격은 시각 연출 생략. 범위 공격은 중심 연출 1회 + 맞은 적마다 가벼운 연출
- 시간 상태별 소리: 히트스톱 중에도 소리는 멈추지 않음. 슬로모·판정 중 효과음 저역통과 + 새 소리 −2반음 + BGM 덕킹. 일시정지·레벨업 중 효과음 정지, BGM은 먹먹하게. UI음은 항상 정상

## 5. 전략카드 시스템 (핵심)

**5.1 기본 규칙**

- 손패 5장, 6초마다 1장 드로우(손패가 가득 차면 정지). 덱은 20장(기본 덱 제공 + 해금 카드로 구성)
- 카드는 최대 3장까지 골라 한 번에 제출 → 판정 1회. 단일 카드 제출도 가능, 제출 쿨다운 3초
- **판정: 기본 성공 30% / 실패 70%**. 보정: 조합 2장 +5%p, 3장 +10%p, 정보 태그 카드 포함 +10%p(중복 불가), 행운·업그레이드. 상한 60%
- 성공: 제출한 카드 전부 소모, 카드 효과 또는 조합 스킬 발동 (금색 플래시)
- 실패: 제출 카드 중 최저 등급 1장만 소멸, 나머지는 손패로 복귀 (카드 균열 + 연기), 작전 경험(OP) +1
- OP 10 누적 → 확정 성공 인장 1개(다음 제출 1회 100% 성공, 최대 2개 보관). 70% 실패가 좌절이 아니라 축적이 되도록 하는 장치
- 판정 연출: 카드 뒤집기 0.6초, 이 동안 게임 속도 0.3배(완전 정지 아님). **단일 카드 판정은 슬로모 없이** 뒤집기만(판정 슬로모가 쌓이지 않게)
- (v0.2) 인장은 자동 사용하지 않고 "인장 걸고 제출"(Shift+Space)로만 쓴다. 2개를 가지고 있으면 OP가 더 쌓이지 않고 게이지가 깜빡임
- (v0.2) 3장 제출 중 레시피에 들지 않은 카드는 성공 시 자기 단일 효과를 함께 내고 소모(손패로 돌려주면 아무 카드나 끼워 +10%p를 공짜로 얻게 되므로)
- (v0.2) 실패 시 소멸할 카드가 같은 등급이면 ① 레시피에 기여하지 않는 카드 → ② 손패에 가장 오래 있던 카드. 고르는 동안 균열 아이콘으로 미리 표시
- (v0.2) 연속 실패 완충: 실패할수록 실제 확률이 조금씩 오르는 분포(장기 평균은 표시 % 그대로, 30%면 최장 연패 8회 이하). 정산에 실제 성공률 공개(8.4)
- (v0.2) 실패 잔효: 실패로 사라지는 카드가 태그별 약한 흔적을 남긴다(보병 소총 3발, 포병 빗나간 포탄 1발, 공군 정찰기 20초 적 표시, 공병 철조망 감속, 의무 소량 회복, 연합 TP +5, 정보 OP +1 추가)

## 11. 사운드·UI·접근성

- BGM: 8/16비트 칩튠 + 군악풍 리듬, 스테이지별 1곡 + 보스곡
- SFX: 타격 / 총성 / 폭발 / UI를 레이어로 구성(어택 0\~30ms + 몸통 50\~150ms + 꼬리)하고 피치 랜덤화, 변형 3개를 연달아 겹치지 않게
- (v0.2) 버스: 마스터 / BGM / 효과음 / UI / 환경, 마스터 리미터. 동시 재생 24, 소리별 재생 간격·상한·우선순위, 같은 프레임 같은 소리는 1번만(음량만 올림). 화면 x 위치로 좌우 팬, 화면 밖은 거리 감쇠
- (v0.2) 소스: 효과음은 코드 합성음(칩튠, 파일 0개)이 기본이고 같은 이름 파일(ogg + mp3)이 있으면 파일 우선. BGM은 상업 이용 가능한 AI 음악 생성기나 BeepBox로 만들고 루프 지점을 다듬는다. 생성 날짜·요금제·약관을 크레딧 표에 기록, 비상업(NC) 소리 금지, 실제 군가·국가·당시 방송 음원 금지
- (v0.2) 판정 소리: 결과와 상관없이 같은 0.6초 예고음(점점 빨라지는 스네어 + 상승음) → 성공 장조 팡파르 + 금색 "칭" / 실패는 250ms 이하 낮고 짧은 둔탁음 + 종이 바스락(성공보다 −6dB, 내려가는 트롬본·부저 같은 조롱조 금지) → OP 적립 "딸깍"이 OP 수만큼 반음씩 오르고 10이면 인장 도장음
- (v0.2) UI 소리: 카드 선택(슬롯마다 음높이 다름)·해제·제출·쿨다운 중 거부·레벨업 등장/선택
- 전투 HUD: 체력, 경험치 바(스테이지 내 Lv 표시), TP 게이지, 고급 스킬 4슬롯(Q·E·R·F) 쿨다운 아이콘, 하단 손패 5장, OP 게이지, 최종 성공률 숫자 하나(내역은 작전판)
- 접근성: 화면 흔들림·점멸 강도 옵션(0\~100%), 아군(청록)·적(적색) 색 구분 + 형태 아이콘 병행(색약 대응), 키 재설정, 모노 출력, UI 볼륨
- (v0.2) 편의 옵션(보상 불이익 없음): 선택 슬로모(켬), 추천 조합 강조(켬), 판정 연출 짧게, 위협 우선 조준(방해원 > 엘리트 > 가까운 적), 마이너스 카드 자동 폐기(OP 3 이상일 때), 신병 모드(받는 피해 −30%, 정산에 표시)
- 메인화면: 사용자가 제출하는 목업에 맞춰 구성(구현은 목업 수령 후)
