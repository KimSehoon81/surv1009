# 밸런스 기록

전투를 헤드리스로 돌리지 않고, 시간 축 해석 모델로 스테이지 난이도를 비교한다(`npm run sim:balance`, 가정은 `src/data/balance.json`).

- **필요 DPS**: 그 시각 스폰 표의 적 체력 유입(초당). 스케일링(§7.3)·대군집 배율·`spawnScale` 포함
- **기대 DPS**: 캐릭터 30명 평균 화력 × 레벨 성장(레벨업당 +8%) × 메타 성장(점령 1개당 +12%) × 범위 배수 1.6 × (1 + 카드 몫 0.25) + 열린 슬롯의 고급 스킬(타임라인 피해 ÷ 쿨다운 × 맞히는 적 4 × 사용률 0.6)
- **기준**: S1의 비율을 클리어율 40~60%(§13)로 두고, S2~S10의 'S1 대비' 비율이 8·12분에서 0.75~1.25 안에서 완만히 어려워지게(S2 약 1.1 → S10 약 0.85). 3분은 도입부라 절대 비율 ≥ 1(초반에 밀리지 않음)만 본다 — S1~S3은 초반 밀도 가산(earlyDensity)이 있어 S1 대비가 흔들림
- **생존 근사**: S1 대비 비율 1 → 50%, 두 배 → 약 80%, 절반 → 약 20%(로지스틱). 절대 확률이 아니라 비교용
- **한계**: 회피·카드 운·대군집(bursts)·보스 패턴 위험은 빠짐. 사람 플레이 체감으로 2차 조정(PROGRESS 이월)

카드 사용 횟수는 스테이지와 거의 무관(마이너스 혼입만 다름)하므로 카드 시뮬(`npm run sim`) 값을 쓴다: 바로바로 제출 판당 145회 · 20초마다 추천 제출 44회(D16), 두 정책 모두 판당 10회 이상 100%.
