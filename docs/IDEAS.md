## 3. 위험·주의

- **확률 보정 과다**: 조합·정보·숙련·완충·예보·무리수가 쌓이면 수치를 읽기 어렵다. 게이지에는 최종값 하나만, 내역은 툴팁.
- **가독성**: 0.5배 카드(60×84)에 포연·노이즈·뒷면·혼탁·예보가 겹친다. 태그 아이콘·테두리 색 영역은 어떤 방해로도 가리지 않는다. 제출이 잦으면 판정 슬로모(0.3배 0.6초)가 쌓이므로 단일 카드 판정은 슬로모 생략 검토.
- **역사 표현(PRD §1)**: 미니미션 "구출"은 고립 아군·통신병만. 피난민 NPC는 안내 역할만, 위험 연출 금지. 보스 작전명은 일반 명칭만, 실제 사건명 금지. 잔효·오폭은 먼지·스파크로만.
- **밸런스 함정**: G5는 실패 시 2배·지속 초기화가 없으면 항상 정답이 된다. G4는 후반 대군집에서 드로우 폭주 → 문턱 상승·분당 상한.
- **범위**: P1(D07~D11)은 이미 빽빽하다. S 비용(G1~G5)만 D07·D09에 흡수, G6·G7은 D12 설계에 포함, 나머지는 P2 이후. 적 1종만 쓰는 행동 부품은 추가하지 않는다.

## 4. 2차 회의(2026-10-11) 요약

- **편의·조작·전략**: 고급 스킬 키 W가 이동과 겹쳐 Q·E·R·F로. "생각은 멈춘 화면에서, 전투 중에는 키 하나로": 빈 선택 Space = 추천 조합, 선택 슬로모 0.6배, 작전판(Tab), 최종 % 하나만 표시, 레벨업 창 0.4초 입력 잠금, 창 벗어나면 자동 일시정지. 행동형 가이드 8개, 진행 원칙(새 요소 분당 1개, 대군집 뒤 20초 숨 고르기, 예고), 패배 전공 50%·보스 재도전 1회, 편의 옵션 → PRD §3·§5.2·§8.4·§11
- **음향**: 이벤트 하나가 화면과 소리를 같이 낸다(feel 프리셋 sfx). 음질보다 보이스 관리(소리별 간격·상한, 전체 24, 같은 프레임 합치기), 3겹 레이어, 히트스톱은 소리를 멈추지 않음·슬로모는 저역통과·정지는 효과음 정지, 판정 소리(예고음 → 팡파르 / 짧은 둔탁음 → OP 적립음 상승), 콤보 5음 음계. 소스는 합성음 기본 + 파일 덮어쓰기 + BGM은 상업 이용 가능한 AI 음악·BeepBox → **기반은 선반영(core/synth, core/audioMix, systems/audio, data/sfx.json)**, 나머지 D08·D15
- **순간 연출**: 착탄 프레임 0에 피해·섬광·시트 첫 프레임 유지·소리·킥, 링은 프레임 1부터. 일반 타격은 국소 정지, 전역 정지는 치명 이상 + 예산 20%, 대형 처치 슬로모는 정지 뒤부터, 프레임당 전체 연출 6건·화면 밖 생략, 범위 공격은 중심 1회. 색 언어(흰 = 착탄 전용, 금 = 치명·성공, 청록 = 아군, 적 = 위협, 회갈 = 잔여물). 데이터 3층(타임라인 → 큐 → 프리셋) → **흔들림·킥·섬광·링·빛 웅덩이·예산은 선반영**, 타임라인·큐는 D10
