## 3. 위험·주의

- **확률 보정 과다**: 조합·정보·숙련·완충·예보·무리수가 쌓이면 수치를 읽기 어렵다. 게이지에는 최종값 하나만, 내역은 툴팁.
- **가독성**: 0.5배 카드(60×84)에 포연·노이즈·뒷면·혼탁·예보가 겹친다. 태그 아이콘·테두리 색 영역은 어떤 방해로도 가리지 않는다. 제출이 잦으면 판정 슬로모(0.3배 0.6초)가 쌓이므로 단일 카드 판정은 슬로모 생략 검토.
- **역사 표현(PRD §1)**: 미니미션 "구출"은 고립 아군·통신병만. 피난민 NPC는 안내 역할만, 위험 연출 금지. 보스 작전명은 일반 명칭만, 실제 사건명 금지. 잔효·오폭은 먼지·스파크로만.
- **밸런스 함정**: G5는 실패 시 2배·지속 초기화가 없으면 항상 정답이 된다. G4는 후반 대군집에서 드로우 폭주 → 문턱 상승·분당 상한.
- **범위**: P1(D07~D11)은 이미 빽빽하다. S 비용(G1~G5)만 D07·D09에 흡수, G6·G7은 D12 설계에 포함, 나머지는 P2 이후. 적 1종만 쓰는 행동 부품은 추가하지 않는다.
