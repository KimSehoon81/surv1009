# 추가 그래픽 프롬프트 (P4·P5, 2026-11-14)

기존 노트북(`tools/art/generate_images.ipynb`, 지금 192장)에 들어 있는 추가분입니다. **P4** 23장(걷기·질주 시트, 적 변형, 주변 생활), **P5** 5장 → 32개(코드가 임시로 그리던 그림 대체). 프롬프트·변환 규격은 `tools/art/catalog.py`에 있고, `python3 tools/art/build.py`로 노트북·`prompts.json`·`prompts_plain_oneline.txt`에 반영해 두었습니다. 그림 스타일·외곽선·투명 배경 규칙은 P1과 같습니다.

## 돌리는 법

1. 저장소의 새 `tools/art/generate_images.ipynb`를 Colab에 다시 올립니다(예전 노트북에는 P4가 없음).
2. `PHASE = "P4"`(또는 `"P5"`), 처음엔 `LIMIT = 1`로 한 장만 보고, 괜찮으면 `LIMIT = 0`. 노트북 맨 위 제목이 "(192장, P1~P5)"면 새 버전입니다.
3. 마지막에 받은 `game_assets.zip`의 `public` 폴더를 저장소 루트에 올리면 끝. 게임은 새 파일이 있으면 자동으로 그것을 씁니다(없으면 지금 모습 그대로).
4. 마음에 안 드는 장만 `REGENERATE = "move_A01"`처럼 다시.

ChatGPT 등에 손으로 붙여 넣을 때는 `tools/art/prompts_plain_oneline.txt`에서 이름(`move_A01` 등)으로 찾아 한 줄씩 복사합니다. 결과 파일 이름을 항목 이름(`move_A01.png`)으로 저장해 노트북의 변환만 모드(`CONVERT_ONLY`)로 돌리면 규격으로 바뀝니다.

## 게임 쪽 (그림 없이도 동작)

- 걷기·달리기·질주: `chars/A01_walk.png`·`A01_run.png`·`A01_sprint.png`가 있으면 예전 `move_slow`·`move_fast` 대신 재생(합성 걸음은 끔). 적은 `E01_walk.png`(평소)·`E01_run.png`(질주)
- 적 겉모습 변형: `enemies.json`의 `looks`. 그림 파일이 있는 변형만 섞임(전투 난수와 따로 골라 판 흐름은 같음)
- 주변 생활: `src/data/ambient.json`. 지역마다 나오는 것이 다르고(서울은 개만, 북부 겨울은 호랑이·개) 화면 가장자리를 천천히 거닐다, 아군 폭탄·포격이나 적 포탄이 가까이 떨어지면 서둘러 화면 밖으로 떠나 사라집니다. 공격 대상이 아니고 다치는 묘사는 없습니다(PRD §1). 그림이 오기 전엔 코드가 그린 단순 도트
- 지형: `src/data/terrain.json`. 굽이치는 개울(건너면 잠깐 느려짐, 그리스군 산악병은 면역), 풀숲·들꽃, 가을 낙엽, 평안도 첫눈·북부 겨울 눈 더미와 언 개울(안 느려짐). 바닥 타일 그림 위에 코드로 그림
